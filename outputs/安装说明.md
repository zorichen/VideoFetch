# 视频下载助手安装说明

**仅限个人学术研究，禁止商业使用。** 请阅读仓库及安装包内的 LICENSE。

## 兼容性

- macOS 13 或更高版本
- Apple Silicon：M1、M2、M3、M4 系列
- Google Chrome

## 安装 macOS 助手

1. 解压 `视频下载助手-macOS应用-0.9-AppleSilicon.zip`。
2. 将“视频下载助手-0.9.app”拖入 Applications。
3. 首次打开若被 macOS 阻止，请前往“系统设置 → 隐私与安全性”，选择“仍要打开”。
4. 允许应用访问 Downloads 文件夹。

## 安装 Chrome 扩展

1. 解压 `视频下载助手-Chrome扩展-1.2.zip`。
2. 在 Chrome 打开 `chrome://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `VideoCaptureExtension` 文件夹。
5. 将扩展固定到 Chrome 工具栏。

## 默认目录

- Chrome 临时写入：`~/Downloads/outputs/<course-name>/`
- 最终归档：`~/projects/renrenjiang/outputs/<course-name>/`
- macOS 助手会自动搬运、转换并验证文件。

以上目录均可调整。在扩展弹窗点击“域名与目录设置”，配置页面域名、媒体 / CDN 域名和下载目录内的输出子目录，点击“授权域名并保存”。Chrome 主下载目录在浏览器设置中调整。

在 macOS 助手选择对应的“Chrome 输入目录”和“输出目录”，选择结果会自动保存。两个目录须独立，不能相同或互相包含；转换期间不能修改。旧文件不会因修改目录自动迁移。直接 MP4 导出仍留在 Chrome 输出目录，助手只搬运及转换 TS。

## 注意

- macOS 应用采用本地临时签名，未经过 Apple Developer ID 公证。
- 当前应用包仅支持 Apple Silicon Mac，不支持 Intel Mac。
- 仅用于你拥有保存权限、且不含 DRM 或加密保护的媒体。
