# 视频下载助手 Chrome 扩展 1.2.0

**仅限个人学术研究，禁止商业使用。** 详见根目录 [LICENSE](../LICENSE)。

本扩展使用 Chrome 调试接口复制正常播放已经返回的媒体响应。结束时允许少量补片：最多 5 个，且不超过总分片数 20%。

## 安装

1. 打开 `chrome://extensions/`。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录。

## 使用

1. 打开已授权保存的视频页面，先暂停视频。
2. 打开扩展，点击“开始捕获”。
3. 从头正常播放完整视频。
4. 每次切换到下一集时，扩展自动下载刚结束的上一集。
5. 最后打开扩展，点击“结束捕获”，停止监听并收尾当前集。
6. 扩展按网页课程标题导出 `.ts` 或直接 `.mp4`。

每集 HLS 同时生成 `.capture.json` 校验清单，包含预计分片数、预计时长、补片数量和总字节数。TS 使用内部会话后缀避免冲突，macOS 助手验证后生成无后缀的正式课时 MP4。

捕获会话会自动识别每个新的有效媒体播放列表，并记录其出现时的课时标题。自动连播或手动切换时立即下载刚结束的上一集；“结束捕获”只负责停止监听并收尾最后一集。某一集失败不会阻止后续视频。

扩展先保存到 Chrome 实际下载目录下的 `<输出子目录>/<课程名称>/`；非课程页面使用“未分类”。点击弹窗“域名与目录设置”可修改输出子目录（默认 `outputs`）、允许的页面域名和媒体 / CDN 域名。每行一个来源，默认 HTTPS，协议、域名及端口精确匹配，子域名需单独配置；保存时按需请求 Chrome 域名权限，下一次捕获生效。完整步骤见[根目录说明](../README.md#配置域名和目录)。

macOS 助手中选择与 Chrome 对应的输入目录和最终输出目录。助手只处理 TS；扩展直接导出的 MP4 保留在 Chrome 输出子目录。

## 安全边界

- 仅允许配置并授权的页面及媒体来源，默认包含人人讲页面、API 和两个媒体域名；未配置网站不会自动放行。
- 检测到 `EXT-X-KEY`、Widevine、FairPlay 或 PlayReady 时停止。
- 分片缺失超过阈值时停止；阈值内按顺序单次补片，不并发、不重试。
- 补片属于额外 CDN 请求，会被服务器记录。
- 补片不跟随重定向，避免跳到未配置来源；若 CDN 重定向，请配置实际媒体来源并重新正常播放。
- 不隐藏 Chrome 的调试提示，不修改请求头，不预取或重试。
- 仅用于你拥有保存权限的内容。

## 原型限制

- 必须在播放前开始捕获；历史缓存不会被追回。
- 只支持单层、未加密 HLS 和直接 MP4。
- 大型视频可能超过 Chrome 调试响应缓冲区或扩展内存限制。
- 当前输出 HLS 为 `.ts`，后续由 macOS 助手无损封装为 MP4。
